# Datasets

Los datasets completos no se incluyen en el repositorio para evitar archivos
pesados y posibles problemas de licencia o privacidad.

- Usa únicamente fuentes autorizadas.
- Conserva las columnas indicadas en `FORMATO.md`.
- No subas direcciones privadas, credenciales ni datos personales.
- `ejemplo_urls.csv` solo demuestra la estructura; no sirve para entrenar
  ni validar el modelo.

Los comandos de entrenamiento y validación están explicados en el
`README.md` principal.
